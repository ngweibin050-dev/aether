# AETHER Lab 审查修复记录（2026-10-30）

依据：《AETHER Lab 全面审查》26 项（P1–P9 物理，M1–M10 三维模型，E1–E7 工程）。以下全部是**仿真与软件**结果，不是实物显示器的测量。

## 1. 清晰度指标改正（P 类）
- 旧指标把 1D 桌面 MTF 除以 0.855（理想眼睛的绝对值），结果连真正的全 2D 全息也只有 70.8%，名称与含义不符。
- 新定义：**同一眼睛焦距下，1D 桌面 ÷ 全 2D 全息**（全 2D = 100%）。另给出 ±0.25 D 景深内的 `in_focus_vs_full_2d_pct`。
- 新发现：眼睛**没有**对焦的那一层，桌面可能超过 100%。原因是桌面的水平方向始终聚焦在面板上，而面板有时比散焦的 2D 像更接近眼睛焦点。这是物理现象，不是程序错误；因此测试只在对焦层比较。

## 2. 斜视几何清晰区
- 眼睛位于 (0, −450, 540) mm，向下约 50° 看。像散 |1/D − 1/d| 必须沿每个点自己的视线计算（d = 眼睛经过该点到面板的距离），而不是竖直高度。
- 旧 `desk_score` 在 +10 cm 报 82.5%，实际视线值是 71.2%。
- 新清晰区（≥80% 全 2D，中心线）：**−108 … +87 mm**。
- 1D/2D 比值按（像散 0–1.5 D，列模糊 0.4–1.3′）预先算成表（同一个 eye.psf），`desk_score` 从约 30 s 降到约 0.4 s。

## 3. 眼睛纵向色差（彩色模式）
Thibos et al., *Applied Optics* 31:3594 (1992)：R(λ) = 1.68524 − 633.46/(λ_nm − 214.102) D。眼睛对 520 nm 聚焦，638 nm 与 450 nm 激光各自额外散焦。

## 4. 真实尺寸 1D 桌面波动仿真（验证 v9/v13 眼模型）
- 竖直方向：相干 1D 子全息，投影像素 p·cos(倾角) = 34.6 µm，场镜背光，传播到眼盒 λd/p，瞳孔弦截取，再成像到视网膜。
- 水平方向：各列互不相干，每条弦按几何散焦加列宽模糊；Gauss–Legendre 弦覆盖圆瞳。
- **结果**：理想复振幅调制时与解析眼模型误差约 1%（面板上 0.855/0.855；0.62 m 处 0.775/0.776）。眼模型因此得到独立的波动光学验证。
- **未解决问题**：纯相位编码（双相位、kinoform）在本模型里产生 0.4–1.7 倍信号的雾光。原因是 10.7 mm 眼盒对 4 mm 瞳孔几乎没有保护带，共轭级与 DC 进入瞳孔。可能的出路：复振幅调制，或更小像素以扩大眼盒、留出保护带。目前作为实验选项，默认不用。

## 5. 图纸 → 三维（M 类）
- 轮廓：marching squares → RDP → 孔嵌套 → 带孔桥的耳切三角化 → 水密拉伸（体积误差 < 3%，0 开放边）。
- 齿轮：标准渐开线（ISO 54 模数），r = mz/2，rb = r cos α，ra = r + m，rf = r − 1.25m；齿半角 π/(2z) + inv α − inv α_R；重合度检查（z20/z30 m2 = 1.605）；啮合相位 φ2 = θ12 + π + π/z2 + δ1·z1/z2，栅格重叠 < 0.5 mm²。
- 按零件类型重建，不再是一张侧视图压平的 2.5D 浮雕：齿轮、轮、销、轴、弹簧、活塞、框架、连杆、板；相啮合齿轮同层，其它按重叠分层；销沿轴向；框架 = 后板 + 隐藏前板 + 支柱。每个尺寸标明来源（图上读到 / 测量 / 假设）。
- 齿轮联动：转一个齿轮，相啮合的按 −z1/z2 转，同轴的同角度。
- 三视图（主、俯、右）→ 视觉外壳（visual hull）→ 水密表面 + Taubin 平滑。限制：看不穿的凹槽、盲孔会被填满；虚线不读取。
- CAD：STL / OBJ / GLB 保持真实毫米导入；STEP 需先导出 STL。
